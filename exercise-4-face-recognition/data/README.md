# Data — Exercise 4 (Face Recognition)

The data, model, and evaluation files are **course-provided** and **not redistributed** here
(the ResNet-50 ONNX model alone is ~91 MB, plus the YouTube Faces video frames and the
evaluation datasets).

## What you need

Place everything under `exercise-4-face-recognition/data/` (paths are resolved automatically
by [`config.py`](../src/cvproj_exc/config.py) relative to the project directory):

```
data/
├── train_data/            # YouTube Faces frames per identity (e.g. Alan_Ball/%04d.jpg)
├── test_data/             # test identities (incl. people not in the training set)
├── resnet50_128.onnx      # FaceNet ResNet-50 model (~91 MB) — OpenCV DNN
├── recognition_gallery.pkl        # (generated by training in ident mode)
├── clustering_gallery.pkl         # (generated by training in cluster mode)
├── evaluation_train_data.pkl      # embeddings + labels for DIR evaluation
├── evaluation_test_data.pkl
└── challenge_train_data.csv       # 128-D vectors + labels for the 5.5 OSR challenge
```

## How to obtain

- **YouTube Faces** frames, the **ResNet-50 ONNX** model, the evaluation `.pkl` files, and
  the challenge CSV are provided with the exercise's supplementary material on the course's
  StudOn page.
- The ONNX model corresponds to the publicly available VGGFace2 ResNet-50
  (https://github.com/ox-vgg/vgg_face2).

## Generated artifacts (not committed)

`recognition_gallery.pkl` and `clustering_gallery.pkl` are produced by running `training.py`
and are git-ignored — regenerate them by enrolling identities.

> All data, the ONNX model, and generated galleries are git-ignored and will never be pushed.
> Only small result/evidence files are kept in `results/`.
