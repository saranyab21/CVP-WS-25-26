# Data — Exercise 5 (CV in the Humanities)

The datasets for this exercise are **course-provided** (art images) and **third-party**
(the balloon detection dataset). They are **not redistributed** here.

## What you need

**1. Art-historical images** (for the Selective Search group task) — provided with the
exercise, grouped by domain:

```
data/
├── arthist/      # art history
├── classarch/    # classical archaeology
└── chrisarch/    # Christian archaeology
```

**2. Balloon dataset** (for the individual detection pipeline) — a small COCO-format object
detection set (Roboflow), split into train / valid / test with `_annotations.coco.json` per
split:

```
data/balloon_dataset/
├── train/
├── valid/
└── test/
```

## How to obtain

- The **art images** come with the exercise materials on the course's StudOn page.
- The **balloon dataset** is a public Roboflow dataset in COCO format; download it and place
  it under `data/balloon_dataset/` as shown above.

## Regenerable artifacts (not committed)

Everything the pipeline writes to `results/` is regenerated by running the scripts and is
git-ignored:

- `results/features/*.npy` — extracted ResNet18 feature vectors (large)
- `results/svm_model.joblib` — the trained SVM
- `results/proposals/`, `results/labeled_proposals/` — intermediate proposal data

Only a small set of final **detection images** and Selective Search visualizations are kept
in the repo as previews.

> All datasets and regenerable `.npy` / model artifacts are git-ignored and never pushed.
